
# Ignacio Fuentes Ribas

This repository powers the GitHub Pages site for Ignacio Fuentes Ribas:

https://ifuentes3.github.io

The site is based on the Academic Pages Jekyll template and has been customized for a professional profile focused on AI, health, clinical translation, and MIT Jameel Clinic leadership.

## Local Preview

```sh
bundle install
bundle exec jekyll serve -l -H localhost
```

Then open:

```text
http://localhost:4000
```

## Main Content

- Home page: `_pages/about.md`
- CV: `_pages/cv.md`
- Publications: `_publications/`
- Talks and events: `_talks/`
- Portfolio: `_portfolio/`
- Site settings: `_config.yml`
- Navigation: `_data/navigation.yml`
